# 裂空：最后航线 · SKYBREAK

原创日式科幻 3D 飞行射击游戏。当前为 **1.8.0**：可见的救援船队、逐区供电与轨道上传，另外两位驾驶员的限时僚机，九条战术专精，以及覆盖 110 个事件的中英日三语配音与敌方指挥官表情。Unity 6000.6.0f1，浏览器在线 / macOS 离线单人版本。

通过实际 Blender / Unity MCP 制作机体、导入资产和构建应用。苍隼适合高速追击，蝠鲼适合宽幅清场与爆破，银针适合远距贯穿。之前的三章任务、机甲超载、驾驶员自然随动继续保留。本轮内容见 [1.8 手机版说明](Docs/更新说明1.8.md)，武装与配乐见 `Docs/音乐与战机更新1.3.md`，验证范围见 [1.8 验证记录](Docs/验证记录1.8.md)。

## 直接开始

双击本目录的 **开始游戏.command**，或打开 **Build/SKYBREAK.app**。在机库选择驾驶员与战机，点击「开始行动」，阅读简报后按 Enter 出击。

也可以打开[网页试玩](https://geduolin1991.github.io/skybreak-last-flight/)，加载完成后点击「进入驾驶舱」启用声音。电脑使用键盘，手机自动启用横屏摇杆与触屏按钮；网页与下载版的进度各自保存。

初次建议「新兵」难度与默认自动射击。可以在系统设置切换标准/王牌难度、鼠标飞行、音量、音乐和震屏。

## 三位驾驶员

所有角色均为原创成年女性。机库、档案与简报立绘有身体轻摆、缓慢呼吸、偶尔侧转和俯身。胸部略微滞后于身体动作并快速收稳，取消独立周期抖动和切换角色时的弹跳。三位角色的节奏与摆幅略有区别。通讯和技能切入保留眨眼与小幅头部动作。

| 驾驶员 | 声音方向 | 战机 / 机甲 | 专属技能 |
|---|---|---|---|
| 苍凛 AOI，24 岁 | 清亮、温柔，带队长的坚定 | 苍隼 / Astra Frame | 蜂群猎手 / 护航指挥 / 疾风突袭 |
| 绯音 RIN，27 岁 | 低柔、慵懒，带成熟的笑意 | 蝠鲼 / Crimson Frame | 攻城熔炉 / 不动壁垒 / 红莲反应堆 |
| 雪璃 YUKI，25 岁 | 清冷、知性，克制而温柔 | 银针 / Oracle Frame | 终点校准 / 时间守望 / 相位游猎 |

共 330 段原创合成录音，三种语言各覆盖 110 个事件；没有使用真人声优的录音或模仿指定人物。机库选机、档案试听、出击、技能、炸弹、受伤、结算和主线通讯有对应语音。进入「系统设置 → 声音与配音」可切换中文、English、日本語，试听当前驾驶员与敌方、关闭配音或单独调节音量。对白播放时音乐与枪炮声会降低，结束后恢复。配音制作与验证范围见 [1.7 更新说明](Docs/更新说明1.7.md)。

三款机甲用 Blender 制作，超载时在实际战斗中展开，手臂与机翼有程序动画。角色立绘是带局部表情帧和轻微变形的二维动画，不是完整 Live2D 模型或可操控的三维人物。

## 行动内容

- **三章主线**：曙光海岸 → 风暴之城 → 寂静天环。每章包含编队战、可选精英指挥机目标与三阶段 Boss。
- **角色通讯与结局**：三位驾驶员参与剧情对话；完成三艘船存活、三片街区供电和轨道上传可得到完整民用行动结局。主线通讯提供三语配音与中文字幕。
- **九条战术专精**：出击前在机库选择，每架飞机三条独有路线，击破获得经验并在本局内升至三阶。
- **双机协同**：金色支援信标召来未被选择的两位驾驶员，基础二十秒，重复拾取延长但不增加人数。
- **九种局内强化**：每次关间从随机三项中选择，覆盖火力、装甲、反应堆、僚机、导弹、精准输出、回血、暴击和技能冷却。
- **章节训练**：通过主线解锁后续章节，可独立练习。
- **无尽航线**：在章节训练页启动，三章循环，敌方生命和弹速逐轮增强，强化持续累积。
- **长期成长**：行动结算产生回收点和驾驶员经验。档案页可以查看角色背景与专属最高分，并进入机体研发。
- **机体研发**：回收点可研发基础伤害、装甲上限和技能冷却。没有付费道具、广告或联网要求。

超载能量来自擦弹、击破与蓝色补给；绿色补给修复装甲，橙色补给补充炸弹。每枚敌弹最多给予一次擦弹奖励。连续 4 秒内击破保持连击，倍率最高 ×10。

个人最高分包含不同难度与模式；驾驶员档案另存各自的最高分。当前版本未区分在线赛季或竞技排行榜。

## 在 Unity 中继续制作

双击 **在Unity中打开.command**，或在 Unity Hub 选择「从磁盘添加项目」，添加本目录。

打开 `Assets/Scenes/Skybreak.unity`，按 Play 即可运行。主场景由游戏导演在运行时生成三维关卡、HUD、敌机和驾驶员。游戏逻辑在 `Assets/Scripts`，着色器在 `Assets/Shaders`，可编辑 Blender 源文件在 `Tools`，导出模型与材质在 `Assets/Art`。

Unity 菜单 **Skybreak** 提供准备工程、构建 macOS 游戏与资源/碰撞规则检查。`Tools` 中保留模型与音频生成程序；这些源生成程序只用于重新制作资源，正常游玩无需 Blender。

## 存档与范围

设置、驾驶员等级、研发、章节解锁与最高分使用 Unity PlayerPrefs 保存在本机，应用标识为 `studio.skybreak.lastflight`。游戏包不需要 Unity 编辑器才能游玩。

这是一个有完整开始、战斗、成长、失败、通关和重玩流程的独立游戏版本。它不包含联机、配音过场、开放世界或经过测试的 Windows 包，也不等同于大型商业作品的资产规模。

## 历史更新：1.1 打击感与音乐增强（配乐已被 1.3 替换）

装甲命中会产生独立撞击音、暖色闪光与短促震动；三种主武器使用不同的发射音色和枪口火光。轻型敌机击破更干脆，重型敌机和 Boss 使用不同的爆炸音、扩散火花、连续殉爆、冲击环与短暂动作停顿。击破分数在战场上浮现，Boss 血条保留短暂伤害残影，受击以红色屏幕边缘反馈。

四首原创配乐重新编曲，战斗加入鼓组、贝斯、吉他合成音色、弦乐铺底与主题旋律；海岸/都市/轨道分别为 142 / 154 / 166 BPM。每章有与基础配乐逐采样对齐的强化声部，在精英、Boss 与机甲超载时平滑叠加。爆炸短暂压低背景音乐，随后恢复。配乐是程序合成的原创作品，不包含商业歌曲、真人演奏或配音。

F12 截图保存在本机 `~/Library/Application Support/Skybreak Studio/SKYBREAK/Screenshots`。

## 1.2 章节与自然随动

三章采用不同的编队顺序与交战节奏，HUD 显示当前目标和支线状态。重型敌机开火前给出 0.65 秒锁定提示；任务通讯会根据支线结果变化。音乐强化层随任务推进、精英交战和高连击调整。敌弹增加深色轮廓，轨道背景降低反光，便于识别战斗目标。

身体动作与胸部随动共用一条姿态轨迹，没有独立弹动周期。原生 16 秒预览位于 **Build/QA/PortraitMotion/驾驶员自然随动_原生预览.webp**。姿态改变后随动很快收住，静止时保持轻微呼吸。机库、档案、简报和结算共用这一效果。

这是基于现有二维立绘的局部变形，不是新增三维人物或完整 Live2D 骨骼。动画采用独立于战斗时间和帧率的计算。原图与原有眨眼资源保留。


## 1.4 裂空冲击与机械首领

炸弹从机体所在位置聚能，随后推出等离子冲击环，配合径向折射、交叉能量环、爆破粒子和分层低频音效；伤害随波前向外传播，每个目标只结算一次。

Boss 的侧翼武装或护盾节点可以独立击毁。护盾在线时本体只承受 28% 伤害，全部节点破坏后有 8 秒核心易伤（×1.65），之后保持失去护盾的状态。各 Boss 拥有四套具名攻击和三个强度阶段，蓄力提示、锁定点与光栅航道提供躲避依据。暴风眼涡轮持续旋转，炽天使六翼根据蓄力与破盾开合。

飞机、敌机和三台 Boss 增加装甲层次、炮管、线圈、进气口与散热结构；港口、都市和轨道场景使用 Blender 制作的详细套件，替换旧场景中的大片方块占位。小型补给和爆炸碎片仍使用简洁几何以保持辨认和性能。
