# 1.12 完整战役验证

最终源码与 Mac / Web 构建的生产资产一致，共核对 972 个非平台元数据文件。独立项目目录、公开仓库和已有 GitHub Pages 站点继续使用，不操作其他游戏项目。

- Mac 运行验证通过 347 项检查，包含完整剧情、三种结局分支、驾驶员尾声、城市交通和天气恢复、轨道机械结构、残骸回收、Boss 反击窗口、安全退场及声音切换。
- 三架飞机分别以新兵难度自然完成三章。测试没有跳过战斗时间、改写 Boss 生命或设置无限生命；使用两倍模拟速度。Boss 仍在 75 / 95 / 110 秒左右出场。
- 最终浏览器通过 49 项剧情检查与 100 项横竖屏检查，包括完整正文、档案回放、三语剧情声音、转屏保护、人物同步、摇杆、多指技能、画质和暂停。
- iPhone WebKit 模拟检查 16 项，Android 模拟检查 8 项；电脑版键盘、选机、音乐、炸弹和暂停均通过。
- 三档画质分别持续实战 12 秒，均约 61 FPS；抽样击破处理峰值约 0.2 ms，音乐连续，绘制尺寸保持稳定。另有 45 秒海岸连续飞行检查，船尾航迹、海岸循环和退出清理均正常。
- 三位驾驶员均完成最终原生 384 帧动画捕获，手机通讯头像另有逐帧对照，敌方出场头像与实际说话者一致。
- 新增 93 段配音经过本地独立识别与波形核验；新增音乐和环境声完成电平与循环接点检查。

性能数字来自这台 Mac 与浏览器设备模拟，不代表所有实体手机帧率。原生独立复测再次通过 347 项检查；180 次连续爆炸的平均帧时间为 17.69 ms，95% 分位为 17.57 ms，99% 分位为 66.35 ms，说明极端压力序列仍有少量帧时间尖峰。击破逻辑峰值 0.133 ms，未创建额外冲击波对象。没有实体手机可供本轮实测。

网页版采用 Brotli 传输压缩，完整主数据约 97 MiB。音乐与环境声在网页包中使用 32 kHz 压缩资源，原始 WAV 与 Mac 版本保留原采样率；配音继续保持原始 24 kHz 源录音。防止执行外来脚本的安全策略、入口校验和只连接本站的限制已检查；资源解压后的字符串扫描没有发现密钥。

详细机器记录见 `战役验证1.12.json`。完整剧情结构与结局条件见 `完整战役与结局_1.12.md`。
