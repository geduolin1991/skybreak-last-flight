# 1.4.0 验证记录

本记录对应裂空冲击波、可破坏 Boss 武装、机械关节与模型场景细化更新。构建、机制测试、三机战役和角色画面均绑定同一构建身份。

## 构建与机制

Unity 6000.6.0f1 / macOS / Metal / Universal Mono，构建成功，0 错误、0 构建警告，发布前 Unity 控制台 0 错误。通过实际 Blender MCP 制作并导出细化模型；Unity MCP 完成导入、构建和模型/音频/碰撞规则检查。

104 项原生机制检查全部通过。覆盖炸弹聚能转爆破、冲击波由近至远命中、目标只受一次伤害、波场与屏幕折射清理；三个 Boss 的模块数量、护盾在线时只承受 28% 伤害、核心 ×1.65 易伤、实际攻击发弹及战败清理；暴风眼 2 个涡轮、炽天使 6 个羽翼的 Blender 转轴保留和实际运动。此前换机音乐连续、六套武装、伤害反馈、技能、机甲、升级、三章推进、重试和机库清理检查继续通过。

复查修正了两处问题：跨场景残留的命中停顿被清理；副武装显示高度抬升以免被 Boss 主装甲遮住。旧命中测试改为在事件触发时确认反馈，避免原生截图或导入造成的等待抖动把短暂闪光漏掉。测试过程中发现的失败未计为通过，修正后重新构建并完整重跑。

记录末尾为 59 FPS，机制测试上限设为 60；这不是全面性能基准。海岸该测试布局的静态渲染器合并记录为 74 → 43。原始结果见 `Build/QA/runtime-results.txt`。

每架战机使用新兵难度、零研发、初始驾驶员等级和默认射击模式。自动控制器通过实际移动、射击、技能、炸弹与碰撞推进三章，优先瞄准仍存活的首领模块。以 2 倍模拟时间运行，不跳关、不锁血、不直接削减首领生命。三架均到达 Victory，并完成三个救援目标。

## 原生画面与声音

已查看炸弹爆破、波前扩散和余波截图，Boss 护盾与破盾后实际弹幕截图，确认有可见扩散过程、能看见独立副武装、涡轮与六翼未脱离模型。港口码头、退台楼群和气密舱/太阳能板场景正常显示。小型补给与碎片仍使用简洁几何；本轮替换的是主要环境方块占位，未声称所有几何都达到大型商业作品规格。

同一构建录制三位角色的机库/档案和 384 帧、24 fps、16 秒原生动作预览，保留用户最新要求的自然随动。关键姿态与界面布局复查未发现人物拉伸、文字截断。动画预览标签现为实际 Application.version 1.4.0。

四首采样乐器配乐和三条强化声部延续 1.3；本轮新增聚能声并重做 2.7 秒分层爆破声。原生检查确认换机不中断音乐、强化声部激活和设备重置后的双轨对齐。没有完成多种耳机、音箱的主观听感验收。

本轮原生玩法测试通过程序控制器运行；没有把自动化鼠标事件当作真人点击验收。此前 CUA 鼠标与 Unity 事件坐标不一致的限制仍记录在 1.3 发布资料中。
