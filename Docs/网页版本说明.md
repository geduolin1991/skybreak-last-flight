# 《裂空》浏览器试玩版

试玩网址：https://geduolin1991.github.io/skybreak-last-flight/

这是由同一套 Unity 游戏工程编译的完整 WebGL 2 游戏。三机种、六种武装、三章关卡、故事、驾驶员成长和 1.4 首领机制都保留。

## 朋友如何试玩

在配有键盘的电脑浏览器中打开链接，等待资源加载后点击「进入驾驶舱」。1.5 初次资源约 56 MB，之后浏览器会缓存游戏资源。无需安装 Unity、Blender 或 GitHub 客户端，也无需登录 GitHub。

默认自动射击；WASD / 方向键移动，Shift 精准移动，空格释放裂空炸弹，Q 驾驶员技能，E 超载，R 切换武器，Esc 暂停。机库中 ← → 选机，Enter 出击。网页下方有全屏按钮。

使用当前版本的电脑 Chrome 或 Edge。手机暂未提供触屏操作。成绩、设置和成长记录保存在当前浏览器中，清理网站数据会清除这些记录，网页进度与 Mac 下载版不互通。

1.5 加入三位驾驶员的 76 句原创合成中文配音。选机时有角色问候；「驾驶员档案」可以试听；「系统设置 → 声音与配音」提供独立音量和开关。台词、字幕与发声驾驶员对应，说话时音乐和枪炮声会降低。音频随资源下载，运行中不调用语音生成服务。详细结果见[1.5 验证记录](配音验证1.5.md)。

## 网页适配

- 启动页提供下载进度、错误重试、操作说明和 Mac 下载入口。
- 点击进入时启用浏览器音频；切换飞机保留机库音乐播放位置。
- 音乐采用浏览器支持的内存压缩加载；音效和强度伴奏继续随战斗混音。
- WebGL 2、Gzip 解压回退和资源缓存适配 GitHub Pages。
- 网页图像使用 2 倍抗锯齿、中等阴影分辨率，并限制高分辨率屏幕的渲染倍率。
- 切换到其他标签时保存并暂停正在进行的战斗。
- 保留运行时动态创建所需的 Unity 组件，避免 IL2CPP 裁剪后缺少碰撞器类型。
- 移除网页中无效的退出应用按钮。

## 构建与发布隔离

安装 Unity **6000.6.0f1** 和 Web Build Support 模块，然后运行：

```sh
python3 Tools/build_web.py --unity /path/to/Unity
```

工具将 `Assets`、`Packages` 和 `ProjectSettings` 复制到 `Build/WebWorkspace`，使用副本编译。主工程的 Mac 设置、已发行应用和 Releases 文件不变。副本为构建缓存，不应在其中制作或保存独有资产。

输出为 `Build/WebWorkspace/Build/Web`。通过本地 HTTP 服务器验证，不能直接双击 HTML 文件运行。构建报告和日志分别位于副本的 `Build/web-build-report.txt` 及主工程 `Build/web-build.log`。

同一个独立 GitHub 仓库中，`main` 保存游戏源码；`gh-pages` 仅存放网页输出和 `.nojekyll`，由 GitHub Pages 发布根目录。不要把 Library、编辑器日志、本地测试数据或其他项目加入发布分支。

Mac 1.4 原生版已有 104 项机制检查和三机种三章通关记录。网页版本另进行实际浏览器的加载、三机种、武器、炸弹、首领、音频、暂停和全屏检查；这不等于所有浏览器与设备的兼容性验收。

2026-09-07 的 1.4 首次网页发布：Unity 报告成功，0 错误、0 警告，网页输出 49,276,014 字节。本机 Chrome 实测三机种六种武器、三机种炸弹消耗与波前、换机时音乐位置递增、Web Audio 实际输出、首领受伤、暂停和全屏均通过，测试过程无浏览器运行错误。首领检查使用既有的生成入口直接进入战斗，未将其描述为网页完整三章通关。

全屏尺寸切换时 Chrome 会记录少量 WebGL `drawBuffers` 警告，画面仍正常显示；保留为后续浏览器兼容性观察项。已验证环境为当前电脑的 Chrome，未完成全部浏览器和低配电脑的测试。

用户要求停止的每两小时自动优化任务保持关闭。
