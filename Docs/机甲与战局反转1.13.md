# 1.13 · 机甲与战局反转

本轮围绕“看得出三台机甲的区别，变身后有不同的战术选择，被救的人能改变战局”调整。基础战役仍为三章与三个结果对应的结局。

## 三款独立原创机甲

| 飞机 / 机甲 | 模型与动态 | 超载玩法 |
| --- | --- | --- |
| 苍隼 / 岚刃 | 六片错层翼刃、非对称刀盾、独立翼根和四肢 | 贯穿追击炮、前方翼刃清场与局部截弹；机动 +18% |
| 蝠鲼 / 赤垒 | 分层红色重甲、圆形炉心、四根肩炮、导弹架和塔盾 | 四联攻城弹与范围爆破；八次有限正面拦弹，机动略降 |
| 银针 / 霜环 | 分体胸甲、开放式脊柱、长磁轨枪、六枚独立浮游棱镜与分段环冠 | 主轴贯穿、多目标棱镜锁定；切换为收束快射 |

模型由 Blender 生成并保留 .blend / FBX，导入 Unity。16,652 / 26,372 / 22,840 三角形；6 / 8 / 11 个活动总成；按材质合并后 30 / 37 / 45 个渲染组件。每台机体拥有独立的合并网格，避免关节资源覆盖。装甲使用向外法线，避免 Blender 双面预览掩盖 Unity 背面剔除问题。

展开通过翼根、炮架、臂腿和浮游机构完成；停止整架模型从零放大的做法。炮口后坐与射击事件同步，浮游总成只有轻微悬浮。还原和转场清除武装残影、迎击盾与变身状态。外观变化不改变白色命中判定核心。

变身保留 R / 触屏“换装”的两种模式。E / 触屏“超载”仍需满能量，持续 8 秒，临界反应堆升级可延长。特效使用固定 12 条轨迹池；普通射击不新增全屏闪光。变身闪光与泛光减弱，让机体与弹幕保持可见。

## 让任务结果进入 Boss 战

三个 Boss 的出场时间仍为战斗第 75、95、110 秒，暂停和剧情不会消耗战斗时间。Boss 进入第二阶段后，完成该章民用目标才会出现一次反击机会；晚完成仍可触发。

| 条件 | 战局变化 | 窗口 |
| --- | --- | --- |
| 第一章三艘救援船仍在 | 船员发来测距数据，标出要塞核心弱点 | 5 秒 |
| 第二章三个街区恢复供电 | 城市电网反相输入，暂时压制风暴护盾 | 6 秒 |
| 第三章身份名册上传完成 | 民用身份回应天环，撤销战争授权 | 7 秒 |

窗口中即使武装节点仍在，核心也会承受 ×1.65 伤害，反应堆补充 25 能量。界面和场景中的信号线同步显示原因；窗口结束后仍存活的护盾节点恢复保护。每场只触发一次，失败目标不会获得免费奖励。

章间剧情补充了舰队测距、城市供能和雪璃旧导航签名被滥用的伏笔。终章中，恢复名册的行为直接改变战斗，之后仍根据真实救援结果进入三个原有结局。

## 音效与配音

新增三种机械展开音、翼刃、攻城炮、棱镜六种原创音效；与现有同步音乐分层和语音压低音乐机制共同工作。新增 7 个事件 × 3 种语言，共 21 段台词；全游戏为 148 个事件、444 个配音文件。沿用原创合成角色声线，不宣称是真人录音。新增台词完成本地独立语音识别与信号检查；专名有识别差异，不等同于母语演员的逐句听审。

## 发布与设备

手机继续推荐横屏，竖屏可玩，人物通讯和触控保留。同一公开链接继续有效。网页构建仅保留当前与前两个版本的生成文件，控制体积；源码历史和既有 Release 下载保留。

原生构建通过 439 项运行检查，三台飞机各自完成一次自动战役到胜利结局。自动驾驶以 2 倍模拟速度运行，未跳过 Boss 出场时间、修改敌人血量或开启无敌；这不等同于人工通关评审。三款机甲的攻击、换装、有限护盾、展开还原与三章条件反击另有针对性检查。

浏览器检查覆盖桌面键盘、Chrome 手机模拟、WebKit 触控，以及横竖屏切换、人物通讯、剧情翻页、三种配音语言和三张地图的持续移动。三档画质的 12 秒采样平均约 61 FPS，切换战斗与画质时音乐持续；这些数据来自 Mac GPU 上的设备模拟。原生 180 次连续击破采样平均帧耗时 17.54 毫秒，99 分位为 49.05 毫秒，仍有偶发尖峰；爆炸冲击对象没有新增分配。

实体手机性能仍取决于机型；桌面 GPU 的手机模拟不能代替真机测试。公开网页发布后还会验证实际下载资源与本地构建一致，并检查首次加载、场景移动和人物通讯。
