# 1.4 · 裂空冲击与机械首领

本轮根据试玩反馈改进炸弹缺少演出、机体和敌机细节不足、首领缺少机制以及环境占位模型的问题。

## 裂空炸弹

按空格后立即消除敌弹并提供短暂无敌，机体周围吸入能量粒子；短暂聚能后发出可见的等离子波前，伴随交叉能量环、径向折射、冲击停顿和低频殉爆声。冲击半径逐步扩大至 32 个世界单位，普通目标 280 伤害、首领 420 基础伤害，仍遵守首领当前护盾/核心倍率。同一波对每个目标只造成一次伤害。过场或重开会清理波场和屏幕折射。

音效为原创合成，保留 `Tools/build_nova_audio.py`，已纳入完整音频重建入口。没有使用现成商业游戏的音效。

## 三种首领

| 首领 | 可拆结构 | 攻击与应对 |
|---|---|---|
| 利维坦 | 左右炮台，各 210 HP | 鱼雷扇面、交错炮击、封锁轰炸、护航拦截；优先拆侧翼，锁定后横向移动 |
| 暴风眼 | 双侧供能武装，各 270 HP | 双涡旋、风暴矛、电弧封锁、雷暴花环；读旋转缺口与蓄力提示 |
| 炽天使 | 三枚轨道节点，各 220 HP | 六翼星芒、零点追猎、裁决光栅、交错曲线环；拆节点后抓住核心窗口 |

护盾在线时核心承受 28% 伤害；全部模块破坏后核心有 8 秒 ×1.65 易伤，随后恢复普通伤害。模块有独立血条，击毁后消除其火力，并触发局部殉爆。首领本体保留三个血量阶段，越后期连发次数增加、休止缩短。新兵预警 1.35 秒，其他难度 1.05 秒；航道激光另有可见蓄力过程。

暴风眼的两个涡轮转轴、炽天使的六个羽翼转轴由 Blender 实际拆分导出；Unity 合并静态材质时保留这些关节。涡轮随阶段加速，羽翼在蓄力和核心暴露时开合。并非用整体模型摇摆代替机械运动。

## 模型与关卡场景

细化 9 件战斗模型：Kestrel / Manta / Needle / Drone / Interceptor / Gunship / Leviathan / Tempest / Seraph。新建 SiegeTurret、ShieldEmitter、HarborPort、StormCity、OrbitHabitat、BasaltIsland 六件资产，工程共 21 种模型。

增加倒角装甲、分层面板、炮口、散热鳍、进气格栅、线圈、线管、检修紧固件；场景包含格构吊机、圆形储罐、带肋货物、退台楼群、幕墙结构、气密舱体、外部管线、太阳能翼与非规则礁石。航道中央仍保持清楚的敌弹对比。

新版可编辑总场景为 `Tools/ProductionModels1.4.blend`；生成程序 `Tools/refine_models_14.py` 从 `Tools/ModelBaselines1.3` 的干净 FBX 增添细节，可重建而不重复叠加。旧单机 .blend 和 1.3 总场景属于历史基线。

## 验证和范围

发布须通过 104 项原生机制检查、三架战机各一条完整新兵战役，以及同构建身份的角色画面回归。最终实际结果见《验证记录.md》。这轮重点改善实战呈现和可学习的首领机制；没有把项目描述成已经达到大型商业游戏的资产规模，也没有把自动通关等同于长期真人平衡验收。
