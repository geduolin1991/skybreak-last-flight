# 1.8 · 掌上航线

同一个公开链接现在会识别手机与平板，自动进入横屏触屏界面。完整的三章关卡、三架飞机、九条专精、330 段三语录音和敌方指挥官继续保留。电脑仍使用原有界面与键盘操作。

## 手机如何玩

1. 打开试玩链接，点击「加载游戏」。首次资源约 100 MB，加载完成后浏览器会缓存。
2. 点击「进入驾驶舱」，将手机横过来。选机、专精、训练、驾驶员档案和设置均可直接点按。
3. 左手在左下方摇杆区域按住拖动；松手即停，战机始终自动开火。
4. 右手使用「技能」「裂空」「超载」「换装」；「精准」切换慢速与小判定点，无需一直按住。
5. 暂停后可以继续、重试或回机库。每章结束直接点选强化；结算和机体研发同样可以触屏操作。

旋转成竖屏、切换应用或失去窗口焦点会暂停战斗并清除方向输入。回到横屏后点击「继续飞行」，不会自动沿旧方向飞走。手机浏览器允许时可点击「全屏」；不允许时仍可在窗口中玩。

「系统设置」中可切换中文、English、日本語配音及音量，保留中文字幕。驾驶员、各机专精和语音语言沿用当前浏览器存档。存档不会自动同步到另一台设备。

手机误识别或使用触屏电脑时，可以从电脑版网页下方点击「触屏操作」；手机设置里也可以切回键盘界面。

## 界面和性能

触屏界面使用独立的大按钮与可滚动菜单，主要操作区至少 44 CSS 像素。生命、Boss 状态与护送船状态集中到顶部；通讯头像和台词缩到侧边，触控区放在飞行区域两侧。状态与冷却来自实际游戏逻辑。

多点触控直接响应每根手指的指针事件，技能无需等到普通鼠标点击才触发。输入带松手清理、取消处理和超时保护；同一次触摸不会重复释放能力。

手机默认将渲染像素倍率限制为 1，减少一次辉光模糊迭代、缩短阴影距离，避免照搬电脑的绘图负担。界面文字使用浏览器原生排版，保持屏幕自身的文字清晰度。首次加载由玩家主动发起。

## 验证范围与浏览器

使用 Chromium 的设备模拟和真实多点触控协议，检查 iPhone 风格的 844 × 390 横屏、390 × 844 竖屏，以及 Android 风格的 667 × 320 小屏幕。测试覆盖双指移动加炸弹、松手、技能、精准、换装、旋转暂停、恢复、菜单选择和刷新保存。

设备模拟不等于实体手机验收。未使用真实 iPhone 或 Android 硬件测量 GPU、温度、内存与长期帧率，较旧或内存较小的手机仍可能加载较慢或卡顿。手机浏览器建议使用更新后的 Safari 或 Chrome；内嵌浏览器的行为由其宿主应用决定。平台支持依据 [Unity Web 浏览器兼容性](https://docs.unity3d.com/6000.0/Documentation/Manual/webgl-browsercompatibility.html)。

输入处理参考 [MDN pointercancel](https://developer.mozilla.org/en-US/docs/Web/API/Element/pointercancel_event)；模拟测试使用 [Chrome DevTools 多点触控协议](https://chromedevtools.github.io/devtools-protocol/tot/Input/#method-dispatchTouchEvent)，以剩余活动触点的变化验证单指抬起和双指同时操作。
