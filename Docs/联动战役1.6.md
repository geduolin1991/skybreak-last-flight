# 裂空 1.6 · 有人生活的航线

这一版把民用行动变成了战场里的真实对象。驾驶员的通讯由目标出现、受到攻击、被击破、供电恢复、上传完成与队友进退触发；不再用固定时间的独白声称背景里发生了不存在的事情。

## 三章的民用行动

| 章节 | 能看到的内容 | 玩家行动与结果 |
|---|---|---|
| 曙光海岸 | 曙光号、归港号、白鹭号三艘救援船，船体起伏、航迹、受损冒烟；港区车辆与细化的岩岸 | 俯冲机锁定救援船后投下可击破的炸弹。击毁飞机或炸弹能阻止袭击。要塞被击破后，仍能航行的船实际驶离；三船存活计为完整救援。 |
| 风暴之城 | 有路面接缝、车道线、斑马线、楼顶设施、车辆和街区窗光的低空都市 | 三座干扰塔各自对应供电区。击破一座，该区逐渐亮起暖色窗灯，车辆加速行驶。三座全部击破才算恢复城市电网。 |
| 寂静天环 | 实体船坞、太阳能翼、跟踪天线、接驳船、轨道链路与更精细的星球 | 击破三个封锁接点后开始八秒识别码上传。上传完成会接通链路并让接驳船进港。仅击破首领不会自动冒充上传成功。 |

击破指挥机仍能获得分数和补给，但不会代替民用行动条件。结局按三章的实际民用结果记录；未完成的目标不会被对白说成全部完成。每章保留原有的编队战、精英、三阶段机械首领及可破坏的护盾节点。

## 双机协同

金色补给是支援信标。拾取后，未被选择的另外两位驾驶员驾驶各自战机从后方进入，跟随玩家编队作战。

- 苍隼僚机发射青色追踪弹。
- 蝠鲼僚机发射宽幅爆破榴弹。
- 银针僚机寻找目标并发射贯穿轨道束。

基础支援持续二十秒，到时加速脱离。新的信标可以延长支援，但不会重复生成更多队友；剩余时间上限为三十八秒。暂停会冻结编队和支援计时，回机库、失败、转章都会清理队友。原“僚机强化”改为真实僚机伤害增加 15%、支援延长五秒。

## 九条战术专精

机库中点击“战术专精”，每架战机可选三条路线，无需先刷解锁。不同战机会记住各自选择。击破敌人与完成民用目标获得专精经验：三十经验进入二阶，八十五经验进入三阶；每局重新成长，关间强化额外叠加。

| 战机 | 路线 | 主要变化 |
|---|---|---|
| 苍隼 | 蜂群猎手 | 加速主炮，高阶追加导引弹；主动技能为贯穿蜂群。 |
| 苍隼 | 护航指挥 | 再生护盾、强化支援；主动技能重建护盾并召回双机。 |
| 苍隼 | 疾风突袭 | 提升机动和擦弹收益；短暂无敌突进并留下伤害脉冲。 |
| 蝠鲼 | 攻城熔炉 | 扩大榴弹溅射；主动技能持续轰击前方区域。 |
| 蝠鲼 | 不动壁垒 | 额外装甲、正面拦截；主动技能修复并展开五秒防壁，高阶在防壁期间继续修复。 |
| 蝠鲼 | 红莲反应堆 | 连射与机动强化；七秒解限，高阶追加燃烧导弹。 |
| 银针 | 终点校准 | 提升轨道炮和精准射击；主动技能追加与敌方损伤相关的处决伤害。 |
| 银针 | 时间守望 | 减缓近身弹幕，再生护盾；主动技能延长强减速领域。 |
| 银针 | 相位游猎 | 高机动，擦弹加速冷却；沿移动方向跃迁并发射相位追击弹。 |

Q 现在使用所选专精的技能。R 继续切换原有两种主武器模式，E 继续展开机甲超载，空格继续使用裂空炸弹。

## 敌人与场景资产

新增俯冲轰炸机、护盾圆环机、轨道炮狙击机、布雷机和无人机母舰，各有不同的轮廓、威胁与应对方式。运输机使用独立货运机模型，不再缩小首领模型充数。

新增十四种 Blender 模型，包括上述机体、救援船、公交车、车辆、干扰塔、船坞、街区、支援信标和细分星球。现有玩家机体、敌机和首领增加装甲接缝、检修盖、铆接细节、炮管、散热口和机械管线；岩岸增加侵蚀表面。海面降低泛光，并增加方向性水纹；都市有清晰路面与恢复供电后的暖色窗光；星球使用多尺度云层、海岸与地表着色。

可编辑来源是 `Tools/LivingCampaign1.6.blend`、`Tools/Environment1.6.blend` 和同目录生成工具。MCP 的后台模型导出因两分钟上限超时后，改用独立 Blender 后台进程完成；输出仍是实际 Blender 几何，经 Unity 导入与材质处理用于游戏。

## 实时通讯与声音

九十八条原创中文合成语音重新录制，总时长约 339 秒。苍凛更清亮、果断；绯音保留低暖和调侃感，开火时增加力度；雪璃保留克制感，在警告、惊喜和连接成功时改变语气。台本见 [实时通讯台本](VOICE-SCREENPLAY-1.6.md)。

这次使用更有情绪起伏的原创参考表演，再保持各角色声线生成台词。使用的 Base 模型不支持逐句情绪指令，因此没有把无效指令当作已实现的表演控制。未使用真人声优的录音或模仿指定人物。合成配音的自然程度仍需要真人试听判断，不能以文字识别通过代替审美验收。

目标失效、离开当前章节或队友已撤离时，相关排队对白会取消；短期战况对白最多等待八秒。危险警告、核心暴露和任务结果优先于低优先级闲谈；字幕跟随实际播放的角色。配音期间保留原有音乐与音效压低、暂停续播和独立音量控制。
