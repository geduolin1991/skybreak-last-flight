# 1.1 打击与声音设计（历史记录）

当前 1.3 的配乐与专属武装见《音乐与战机更新1.3.md》；以下保留早期设计记录。

用户反馈是本轮的验收依据：命中反应和打击感偏弱，音乐缺少推进力。本轮先修正反馈链缺项，再增加不同状态的差异。

## 命中

三种主武器分别使用脉冲、散射、离子发射音。每次开火产生短枪口闪焰与轻微机身后坐。弹体接触装甲时产生金色短火花、暖色装甲闪光和独立撞击声；机身有短促震动，碰撞位置不随视觉震动变化。

装甲反馈持续约 95 毫秒，撞击声限制触发频率，避免密集火力变成失控叠音。Boss 血条用较亮的残影显示刚刚被削去的生命，随后追上当前生命。

## 击破

轻型目标使用短而干脆的爆破。重型目标增加低频爆炸、三次后续殉爆、冲击环和约 48 毫秒的动作减速；Boss 使用独立的长尾爆破、十一组后续爆炸与约 120 毫秒动作减速。火花拉成长条，烟尘保留柔边，碎片与火光分开。

击破分数在目标附近浮起，重型目标突出 BREAK，连击每提升一个倍率播放提示音。重要爆炸短暂降低配乐，让撞击的起点更容易听清；音乐随后平滑恢复。

玩家受伤使用红色屏幕边缘和冲击音，保留无敌保护；镜头震动仍可在设置关闭。

## 音乐

| 航段 | 速度 | 配器与结构 |
|---|---|---|
| 曙光海岸 | 142 BPM | 明亮旋律、连续贝斯、鼓组，主旋律段落加入吉他合成音色 |
| 风暴之城 | 154 BPM | 切分贝斯与更紧的鼓组，强化声部增加攻击性 |
| 寂静天环 | 166 BPM | 更快的终局推进、上方旋律与空间铺底 |
| 机库 | 104 BPM | 较轻的旋律、低音与弦乐合成铺底 |

四首原创作品使用 44.1 kHz 立体声。战斗曲包含引入、发展、过渡、主旋律、对比段与循环回转。每首战斗曲另有一条完全等长、逐采样对齐的强化声部，两轨共用播放起点。精英目标、Boss、机甲超载依次提高强化层比例，离开后平滑回落。

基本曲目母带 RMS 约 0.172–0.174，强化层约 0.134；音效保留瞬态。离线输出最高峰低于 0.95，运行时为枪声、撞击和爆炸留出混合空间。该数值是文件幅度检查，不代表完整的响度标准认证。

所有音乐和音效由工程内的生成程序原创合成，没有使用商业歌曲、未经许可录音或真人配音。源程序位于 Tools/build_audio.py，游戏资源位于 Assets/Resources/Audio，试听片段位于 Build/AudioPreview。

## 验证与边界

机制检查确认了命中音源在播放、材质闪光和震动正在发生、重型击破序列已生成、超载混音系数提升，以及三首强化层和主曲的样本数一致。实际截图用于检查命中与击破显示；完整自然战斗模拟检查反馈加入后是否影响通关流程。

音色是否合口味、长时间聆听是否疲劳，以及不同耳机/音箱的低频效果，仍应以用户试听为准。下一轮优先依据用户反馈调整混音和编曲，不凭音量大小判定质量。

1.1 自然战斗复测结果：435.5 秒游戏时间通关，三处救援完成。运行时观察到一次系统音频设备重置，因此加入双轨统一进度和播放起点的恢复处理，并对该处理进行模拟调用检查。
