# 驾驶员动作 · 1.2.0 自然随动修订

用户反馈上一轮胸部运动过于刻意。本轮取消独立周期起伏、呼气时的弹动、转身/俯身的额外冲击和选中角色时的弹跳，改为身体动作带动的轻微随动。

## 最终动作

- 身体轻摆约 6.6 秒一周期，呼吸约 3.6 秒一周期；三位驾驶员的节奏和幅度略有区别。
- 约 16 秒的姿态序列中，有一次小角度侧转和一次轻微俯身，进入和退出都平滑过渡。
- 胸部跟随同一条身体动作轨迹，使用约 0.10–0.36 秒的加权滞后。没有独立振荡；姿态停止后，附加随动很快收住。
- 减小全身摇摆、呼吸和胸部的位移，左右区域保持协调，衣服随身体一起移动。
- 通讯与技能面部特写继续抑制躯干姿态和胸部随动，保持面部稳定。

## 验证方法

使用真实 Unity Metal 独立应用录制三张机库、三张档案和三角色同屏 384 帧，24 fps、16 秒。录制禁用存档写入，静音并自动关闭；使用与正常游戏相同的动画计算和着色器。原生录制身份与实际应用绑定，发布前必须一致。

自然随动预览：`Build/QA/PortraitMotion/驾驶员自然随动_原生预览.webp`。原始帧：`Build/PortraitCapture1.2-Natural/Frames`。检查记录：`Build/QA/PortraitMotion/visual-review.md`。

这是二维立绘的局部变形。转身、俯身是小角度透视暗示，不能表现新的三维侧面。16 秒预览用于观察动作，首尾不是无缝循环。

旧版独立 WebGL 工具仅适用于历史标量动画。自然版使用向量姿态历史，工具会明确提示改用原生录制，避免误用旧预览。

修改前动作源码保存在 `Build/Backups/pre-natural-portrait`；较强动作的原生检查保存在 `Build/MCP-1.2/Before-user-natural-motion`。用户的最新偏好是自然、协调的随动，后续优化不应再次自动增加独立胸部抖动。
