# 1.5 配音与游戏验证

## 构建与资源

Unity 6000.6.0f1 的 macOS 与 WebGL 构建均成功，报告为 0 错误、0 构建警告。最终网页文件合计 56,033,013 字节。所有音频保存在游戏资源中，运行时不需要下载模型或连接语音生成服务。

- macOS 构建身份：`eb346f2914d5d1ef787e55b1f497d9db7899f05aa4547d4c09d322cd7a112ab7`
- WebGL 构建身份：`2173299d516f00ae74c9294837530aa837134bf804c328c6b6498bfb86b00660`

两平台使用独立构建设置，所以身份不同。网页构建在 `Build/WebWorkspace` 副本完成。模型预制体被 Unity 重新生成了内部文件编号，检查其网格、材质、命名和局部姿态集合与原版本相同。

76 句语音共 270.206 秒，24 kHz 单声道。Unity 已核对清单、资源路径与时长；独立 ASR 与波形检查结果保存在 [配音资产记录](配音资产记录1.5.json)。最大样本峰值 0.804，没有削波；没有超过 15% 拼音音节差异阈值的台词。ASR 忽略声调与同音字，这不是逐句真人听审或对演出自然度的保证。

## 浏览器配音交互

使用本机 Chrome 和实际网页成品，通过页面按钮、游戏内按钮和键盘输入验证。读取游戏只读状态确认播放条目、时间和音量；测试浏览器另安装临时音频分析节点观测实际输出，该探针不包含在发布网页中。

- 点击「进入驾驶舱」之前不播放角色语音；点击后启用。
- 三位角色选机和档案试听均对应自身音频；左右换机时机库音乐时间持续前进。
- 配音期间机库音乐增益从 0.468 降至约 0.253，结束后恢复；这是默认总音量下的实际数值。
- 配音开关和音量调整生效，刷新后仍保留；关闭时点击试听不会播放。
- 关闭背景音乐后单独测量角色人声输出，连续观测以避开台词中的自然停顿。
- 三位角色的任务简报、出击、Q 技能、空格炸弹有对应语音。
- 游戏暂停时人声停止推进，继续后从先前位置恢复。
- 关卡自然推进到 24 秒通讯，播放苍凛的护航台词；普通技能和炸弹短语不覆盖重要对白。低装甲警告保留更高优先级。

这不是全部浏览器和设备的兼容性验收，也不是三章网页真人通关。既有的首领和武装回归范围见历史 [1.4 记录](验证记录.md)及[网页说明](网页版本说明.md)。

源码和网页成品继续只发布在独立的 `skybreak-last-flight` 仓库。每两小时自动优化任务保持关闭。
