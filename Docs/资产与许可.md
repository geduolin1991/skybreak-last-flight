# 资产与许可

## 1.5 驾驶员声音

76 句中文对白与三份角色参考音均为本项目原创合成资产。先用 Qwen3-TTS VoiceDesign 按成年角色设定生成三条原创声线，再以这些合成参考音制作固定角色的台词；未提供真人录音、声优样本或既有作品对白作为参考。角色方向、参考文本与种子在 `Tools/voice_cast.json`，合成参考音在 `Tools/VoiceReferences`，游戏台词清单在 `Assets/Resources/Voices/voice-bank.json`。

本机制作使用 `mlx-community/Qwen3-TTS-12Hz-1.7B-VoiceDesign-bf16`、`Qwen3-TTS-12Hz-1.7B-Base-bf16` 和 MLX Audio 0.5.1。模型文件和 Python 环境不包含在游戏或源码仓库中。保留 [Qwen3-TTS Apache 2.0 许可](Licenses/Qwen3-TTS-LICENSE.txt)与 [MLX Audio 许可](Licenses/MLX-Audio-LICENSE.txt)；模型项目见 [Qwen3-TTS](https://huggingface.co/Qwen/Qwen3-TTS-12Hz-1.7B-VoiceDesign)、工具项目见 [MLX Audio](https://github.com/Blaizzy/mlx-audio)。第三方工具许可不等同于对整个游戏资产授予统一许可证。

## 动漫扩展资产

三位驾驶员及闭眼表情帧使用内置 image_gen 原创生成，保存于 `Assets/Resources/Pilots`。最终提示词保存在 `Docs/ArtDirection/角色提示词.md`。动态效果由 Unity 中的局部表情混合与着色器驱动。

新增 Astra Frame、Crimson Frame、Oracle Frame 三款空战机甲由 Blender 原创制作，均保留 `.blend` 和 FBX 文件。动漫扩展阶段合计十二种 3D 模型，不使用现有动漫角色或机甲模型。

## 1.2 章节资产

新增 EvacCarrier、StormRelay、OrbitalGate 三份原创环境模型，通过 Blender MCP 制作，分别保留 `.blend` 和 FBX；加上原有模型，源码现有十五种模型资产。`WorldLandmarkWorkshop.blend` 是本轮资产制作与渲染工作区。三份资产已在 Unity 中完成导入、材质转换和实际游戏画面检查，包含于 1.2.0 原生应用。

## 1.3 战机重建

Kestrel、Manta、Needle 已通过 Blender MCP 重新制作，导出覆盖同名 FBX。当前可编辑总场景为 `Tools/ShipArsenalWorkshop.blend`，生成器为 `Tools/build_ship_arsenal.py`。旧的同名单机 `.blend` 是早期版本备份，重建新版请使用本总场景。

## 1.4 战斗模型与环境套件

9 件战斗模型经 Blender MCP 细化；新增 6 件原创武装/场景模型，模型总数 21。最新可编辑生产场景为 `Tools/ProductionModels1.4.blend`，可重复生成器为 `Tools/refine_models_14.py`，基础输入保存在 `Tools/ModelBaselines1.3`。新爆炸和聚能声音为项目原创合成。模型网格、材质、特效与声音均包含在可玩包中，源文件包含在源码包中。


## 1.6 新增资产

本轮十四种新增模型与现有模型细化均由项目内 Blender 工具原创制作，源场景为 `Tools/LivingCampaign1.6.blend` 与 `Tools/Environment1.6.blend`。没有新增第三方游戏模型。九十八条配音使用本地 Qwen3-TTS 生成新的原创角色声线，未使用真人录音；Qwen 模型和工具的许可延续 1.5 的记录。1.6 新参考片段位于 `Tools/VoiceReferences1.6`，方向与台本见 `Tools/voice_cast_16.json` 和 `Docs/VOICE-SCREENPLAY-1.6.md`。

## 1.7 新增资产

三位敌方指挥官的九个表情帧由内置图像生成工具原创制作，最终提示词和三张图集路径见 `BossArt-1.7.md`。本轮无真人肖像或既有游戏角色参考。新增英文、日文驾驶员录音和三语敌方录音全部在本地合成，没有使用真人声优样本。日语读音文本使用 pykakasi 转换后按脚本复核；核验使用本地 Qwen3-ASR 与 [MLX Whisper large-v3-turbo](https://huggingface.co/mlx-community/whisper-large-v3-turbo)。模型权重仅在本机工具目录，用于生产与核验，不随游戏分发。工具许可与项目语音依赖保持明确分离。

## 1.9 新增环境资产

CoastalBreakwater、CivicPlaza、OrbitalTruss 为本项目通过 Blender 5.2.1 后台 Python 接口原创制作，包含倒角结构、导航灯、树木、座椅、水池、桁架和太阳能板。源场景为 `Tools/Environment1.9.blend`，生成器为 `Tools/build_environment_19.py`。导出时模型分别有 3,512、3,928、2,416 个顶点，Unity 导入后因法线与材质拆分可能增加。未新增第三方下载模型、录音或贴图。
