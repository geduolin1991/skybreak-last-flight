# 1.9 · 航线节奏与环境光影

第一场利维坦战改为起飞后 **75 秒**生成，原版约为 119 秒。时间按实际战斗计算，简报、暂停不占用计时；Boss 入场移动仍需几秒。第二、三关分别在 95、110 秒进入 Boss 战，逐步增加任务和弹幕压力。

## 重新编排的战斗

| 第一关战斗时间 | 战斗段落 | 玩家实际面对的变化 |
|---|---|---|
| 0–12 秒 | 接敌 | 三机先锋编队起步，先建立移动、自动射击和读弹的感觉。 |
| 12–30 秒 | 救援 | 两次定向袭船轰炸，炸弹能被击落；掩护机从侧翼进入。金色信标为反击准备双机支援。 |
| 30–48 秒 | 反击 | 指挥母机和首次轨道炮威胁；击破指挥机获得真实支援、修复和能量。 |
| 48–54 秒 | 补给 | 敌机转向撤离，停止普通刷怪，投放两件补给，连击计时延长。 |
| 54–70 秒 | 突破 | 护盾机、轨道炮、重炮机按不同波次出场；最后一次袭船攻击。 |
| 70–75 秒 | 警戒 | 敌机退出，音乐回落，给出五秒 Boss 预告。 |
| 75 秒起 | 决战 | 利维坦进场；拆炮台、破盾、核心集中输出。阶段转换留出短暂重整时间。 |

普通波次按同时存活的敌机数控制数量。离场敌机真正飞出视野，不会凭空变成击破奖励；未处理的炸弹仍按原规则落向船体。补给段也不会自动摧毁尚未完成的地面目标。

第二关强调城市电网与交叉火力，第三关强调封锁接点和识别上传。每章都保留反击、补给和预告三个不同的强度层次，不再从头到尾重复同一种刷怪频率。

## 战斗结果进入故事

- 城市干扰塔和轨道接点分三次出现。击破、街区亮灯、车辆移动、上传与进港仍由真实任务状态驱动。
- 第一关三艘船全部保住，第二关开场获得船队送来的支援信标。
- 第二关三个街区全部恢复供电，第三关开场增加 35 点反应堆能量。
- 城市供电恢复后，雷暴走廊由双线封锁减为间隔更长的单线攻击；轨道识别上传完成后，环境封锁光束停止。
- 关后强化界面会说明这一关救援的实际结果，以及下一关获得的帮助；手机端同步显示。
- 继续使用完整中英日配音。没有新增无录音的旁白冒充语音；失去目标或已经撤离的敌机，不再触发过时警告。

## 光影与背景

- 海面改为可接受主光、镜面反射和物体阴影的材质。大小水纹交错，救援船的尾流随位置、航行和失能状态变化。
- 城市地面增加不规则积水、细小雨纹、铺装缝隙、路灯反光；细线根据屏幕像素宽度做平滑处理，减少远处闪烁。
- 海岸用暖色晨光与冷色补光，城市保持雨中冷光，轨道保持冷色轮廓和暖色反射。减轻近景雾感与暗角，压缩过亮部分以保留金属、反应堆和爆炸内部的层次。
- Blender 新制作三套原创细节：防波堤与导航灯、带树木座椅和水池的城市广场、带太阳能板的轨道桁架。可编辑场景为 `Tools/Environment1.9.blend`。

## 声音与性能

音乐继续使用同一首循环配乐及同步强化声部，根据接敌、反击、补给、Boss 阶段改变混音。Boss 预告前压低伴奏，入场后逐层升高；换机不重新播放音乐。

静态广场、道路、建筑按材质合并，车辆保留独立运动。城市窗口只有在供电渐变时更新材质参数；180 个轨道星点合成一份网格。手机继续使用较低的阴影和辉光开销，战斗保留对象复用及粒子上限。

检查结果和设备限制见 [1.9 验证记录](验证记录1.9.md)。本轮没有恢复每两小时自动优化任务。
