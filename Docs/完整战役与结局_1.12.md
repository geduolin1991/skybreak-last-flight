# 《裂空：最后航线》完整战役 · 1.12

故事发生在停火后的第七天。轨道防卫网络“天环”仍执行净空协议，拒绝民用识别码。苍凛、绯音和雪璃必须从海上撤离行动一路突破城市干扰网络，把真实的人类身份送进天环。

第一章“曙光海岸”护送曙光、归港、白鹭三艘撤离船，船上分别有 312、268、190 人。港口航标、波浪、船尾航迹和侧翼设施构成可读的海上航线。拦截轰炸机、打开封锁，在战斗时间约 75 秒迎战加兰指挥的利维坦。失去一艘船不会强制游戏结束，但会记录在最终结果中。

第二章“风暴之城”回收导航数据，摧毁三个干扰节点。医院、架空轨道和撤离车辆把任务与城市联系起来；对应街区恢复供电后，列车与巴士开始移动，雨势逐步减弱。约 95 秒迎战卡西娅与风暴机体。

第三章“寂静天环”夺回三条轨道链路，守住八秒身份上传窗口。太阳翼和通信天线随链路恢复对准工作方向，接驳船完成避难行动。约 110 秒迎战诺克特与天环核心。拆除护盾节点后，每轮攻势结束会出现短暂核心易伤机会。

序幕、两段章间和三章开场串起三位驾驶员的选择。全部剧情可逐页推进、自动播放或跳过，战斗时间不会在剧情界面继续流逝。中、英、日三个配音版本使用相同事件触发，字幕保留中文。

## 三种结局

- **再一次黎明**：三艘撤离船全部通过封锁、城市三处供电全部恢复、轨道身份上传完成。
- **带着名字归航**：身份上传完成，但此前的民用目标没有全部完成；结算如实列出幸存船只与人数。
- **最后的守望**：击毁核心停止攻击，但上传未完成，小队留下继续人工引导航线。

每种结局之后，都有当前驾驶员的个人尾声。已完成的剧情和结局可在“章节训练 → 战役档案”中重温；档案保存对应结局的世界状态，重新出击不会改写旧结局的场景。
