# 1.2.0 全游戏优化

使用实际 Blender 和 Unity MCP 完成资产制作、导入、构建与原生检查。新版包含章节场景、关卡节奏、故事通讯、战斗可读性和驾驶员自然随动；原始检查数据及范围见《验证记录》。

## 制作连接

- Unity MCP for Unity 10.2.0 与本轮核对的最新稳定发布一致。用户明确回复“我同意”后，已在编辑器窗口接受条款；实际读取编辑器状态、控制台、执行 macOS 构建和模型/音频资源检查。
- Blender Lab MCP 1.0.0，固定官方源码提交 4309a39646e644261624bfcd2bca669b343b7621。实际创建几何和材质、导出 FBX、渲染预览并重新导入验证。
- 两者通过本机连接使用，未添加付费生成服务或 API 密钥。Unity 编辑器编译后会重新连接；曾出现端口释放延迟，插件自动切换本机端口后恢复，后续构建调用成功。

每件资产保留独立 .blend 和 FBX。上表不是 Unity 三角面或帧率统计。三份 FBX 的范围和材质经过 Blender 重新导入检查，并在原生游戏画面中确认。

航母位于近海航线，中继站位于都市两侧，星门位于轨道飞行平面下方。原生复查发现星门亮度会干扰首领辨认，已使用独立背景材质降低反光和发光。近海与都市加入低空薄雾，都市支援目标完成后光照逐渐回升。船只为场景资产，没有独立损伤或护送 AI；薄雾不是体积云。

同一区域静态不透明网格按材质合并，保留粒子和线条，生成资源随场景释放。原生检查记录海岸静态区域渲染器由 528 个降至 50 个；没有据此推算帧率倍数。

## 玩法、关卡和故事

三章采用各自的十二段编队序列：海岸清理撤离航线，都市交叉火力，轨道交替扫掠。后半章重型增援集中在 80 秒之后，给中段精英目标保留更清晰的交战窗口。

每章在 0 / 24 / 52 / 80 / 115 秒推进任务节点。HUD 整合当前目标、支线状态与精英血量。通讯在推进节点给出引导，最终接近阶段根据支线成功与否变化。原有三章首领、九种强化、三位技能、成长、训练、无尽循环和救援结局继续使用完整流程。

重型敌机和侧翼交叉火力提前 0.65 秒显示瞄准提示，开火朝已锁定的位置发射。原生检查确认预警可见、锁定不追随玩家的新位置、开火后提示清除。猎手导弹对重型目标给予更高的追踪权重。

## 反馈、音乐和角色

敌弹增加深色轮廓并保留彩色弹体与亮色核心，采用批量实例绘制。命中声根据左右位置轻微偏转；反应堆充满时增加一次提示。原有命中闪光、后坐、分数浮现、重型殉爆和短暂动作停顿继续生效。

沿用 1.1 的原创电子摇滚与音效素材，音乐强化层随任务推进、精英、首领、超载和较高连击改变。原生检查覆盖三章采样对齐、实际强化层播放、超载增益与设备恢复重同步；没有进行多设备听感验收。

根据用户最新反馈，取消过于刻意的独立胸部周期起伏和额外弹跳。角色以轻微呼吸、小角度侧转和俯身带动柔和随动，姿态停下后迅速收稳。实际 Unity 应用录制了三位角色、384 帧、24 fps、16 秒预览，检查面部、服装和透明边缘。角色是二维动态立绘，不能表现新的三维侧面。
