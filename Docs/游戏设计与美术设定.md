# 裂空：最后航线 / SKYBREAK

## 游戏定位

原创单人纵向飞行射击游戏。以三维硬表面战机、连续滚动的立体环境和高对比弹幕构成画面，保留街机射击的即时操作感。完整行动为三章，每章约 115 秒编队战，之后进入三阶段 Boss 战；实际时长随玩家输出和失败次数变化，目标一次行动约 8–12 分钟。

本次版本交付的闭环：机库选机 → 难度与操作设置 → 任务简报 → 关卡战斗 → Boss → 三选一强化 → 后续章节 → 结局与评级。失败可立即重试，通关过的后续章节可以单独训练。机体选择、设置、最高分和章节解锁保存在本机。

## 核心操作与反馈

- 飞机沿固定航线向前推进，玩家在飞行平面上自由移动，采用略倾斜的俯视相机。
- 默认自动射击；可关闭，改用 Z 或鼠标左键。
- Shift 将移动速度降低至 42%，显示白色核心判定点并收束主要弹道。机翼不是受击判定范围。
- 敌弹为橙红或紫色，玩家主弹为青蓝，追踪导弹为浅蓝。发射方向、速度和武器形状共同区分敌我。
- 受伤扣除 1 点装甲，并获得 2.5 秒保护。受击后局部清除附近敌弹，避免同一密集弹幕瞬间连续扣血。
- 高速弹使用线段扫掠检测，避免低帧率时穿过碰撞点。
- 每枚敌弹只计算一次擦弹；在核心外侧近距离穿越会增加分数和超载能量。
- 炸弹清除敌弹，对普通敌机造成大范围伤害，对 Boss 造成固定伤害，并短暂无敌。
- 超载消耗 100 能量，基础持续 8 秒：提高射速和伤害，追加高亮弹道，启动时消弹。擦弹、击破和补给可充能。
- 命中亮闪、碎片、火光、烟尘、合成音效及可关闭的震屏共同构成反馈。

## 三款战机与三种武装

| 战机 | 操作特性 | 初始武装 | 额外特性 |
|---|---|---|---|
| F–07 苍隼 / Kestrel | 均衡速度 | 脉冲阵列 | 默认推荐机体 |
| B–12 蝠鲼 / Manta | 移动略慢，翼面较宽 | 飓风散射 | 装甲上限 +1，追踪导弹发射更频繁 |
| X–03 银针 / Needle | 最高移动速度 | 离子长矛 | 更适合高机动精确输出 |

## 敌人和节奏

轻型无人机负责建立节拍；拦截机用瞄准扇形弹制造移动压力；重装机与运输机迫使玩家维持输出，并提供恢复资源。波次由固定的七种编队模板组合，左右进入、横列、错位纵列、护卫编队与重型单位交替。

每章五个阶段：进入与教学 → 轻型编队 → 重型压制与补给 → 交叉火力 → Boss 警报与交战。城市和轨道后半段加入激光落点预警。激光在开火前约 1.75 秒显示细线，之后变为粗亮光束；留出明确撤离时间。

Boss 在 67% 与 33% 生命处切换阶段，切阶段消弹以重置局面。攻击包含旋转环、双炮瞄准扇形、波动弹墙；后段加入预警激光。第三章增加弹数和多条激光，危机逐层推进。

## 三章剧情

背景：2191 年，为保护人类建立的轨道防御网络「天环」收到错误的战争指令，把人类通讯识别成敌方伪装。海上撤离船队是最后一批仍未失联的人。玩家驾驶不依赖天环导航的旧式战机，与苍凛、绯音、雪璃组成的小队共同打通三层封锁。

### 01 曙光海岸

海上跑道、货运平台和碎裂岛屿向身后流去。冷青海水衬托推进器与橙红炮火。目标是为撤离船队打开出海口。Boss「利维坦」是装配重型炮台的海上封锁要塞。

完成后，小队确认船队通过封锁。海上的战斗只是外围，干扰的源头仍在城市。

### 02 风暴之城

高层建筑形成峡谷，青色窗带和橙色交通光线描出都市轮廓。城市道路上方开始出现蓄力激光。Boss「暴风眼」采用宽翼新月轮廓与双涡轮反应井，负责维持都市空域封锁。

击破后，雷暴干扰解除，人类通讯短暂回归。雪璃定位到轨道主机，战机准备爬升。

### 03 寂静天环

蓝色行星、深空星点、太阳能阵列和轨道设施构成最后航段。紫色核心与橙色弹幕强化终局识别。Boss「炽天使」将核心外露，采用六翼放射轮廓，拥有环形反应堆和多条预警激光。

最后一击并非摧毁行星，而是切断错误战争指令。天环再次接收人类识别码，撤离船队看见归岸灯光。结局用中文文本呈现，不包含配音过场。

## 强化、评分与重玩

两次关间选择，每次从九种强化中随机抽取三种。以下为基础三项，其余六项、长期成长、动漫角色与无尽航线详见《动漫增强版.md》：

| 强化 | 效果 |
|---|---|
| 火力校准 | 伤害系数 +0.15，射速 +12%，脉冲增加弹道 |
| 复合装甲 | 最大装甲 +2，立即修复 3 |
| 临界反应堆 | 擦弹/击破充能提升，超载 +1 秒，补炸弹与能量 |

连续 4 秒内击破会维持连击，每 8 连击提高倍率，最高 ×10。擦弹额外计分；消弹转化奖励；Boss 击破和残余装甲提供奖励。当前版本保存一个本机最高分，不接入在线排行榜，也不使用微交易或广告。

新兵 / 标准 / 王牌分别提供不同的装甲、炸弹、敌弹速度与波次间隔。三个难度共享个人最高分。章节训练按主线进度解锁。

## 视觉规范

- 基底：深海蓝、钛灰、陶瓷白。主战机是明亮的白色硬表面轮廓，配深色座舱与双喷口。
- 友方：青蓝发光；敌方：橙红主弹、紫色高级弹；修复：绿色。
- 真正的三维模型参与金属/粗糙度光照、投影、倾斜与滚动。光晕采用后处理，避免靠二维背景假装三维。
- HUD 尽量占两侧：左侧装甲/武装/炸弹，右侧分数/连击/反应堆；中央保留战斗可视区。
- 关键中文标题与任务文本使用 Noto Sans CJK，按钮留足高度，机库和暂停界面可鼠标操作。
- 美术方向为清晰、冷峻的科幻街机风格，不宣称达到写实 AAA 资产制作规模。
