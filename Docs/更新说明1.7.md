# 裂空 1.7 · 对手的声音

本轮围绕连续击破的流畅度、空中与地面的分层、完整三语配音和有性格的敌方指挥官展开。

## 流畅度与可读性

修复新增敌机、地雷和炸弹被笼统归为重型目标的问题。普通敌机与重装敌机被击毁时不再压慢玩家移动；Boss 最终击破和裂空炸弹保留短促的停顿。重装目标仍有分段爆炸、冲击环、音效和得分反馈。

敌机模型与冲击环按实例复用。战斗音效提前准备，角色音频异步预载；受到打击时才更新敌机的闪光材质参数。小弹丸使用 77 顶点网格，爆炸粒子保留烟、火与碎片层次，同时限制总量。后期辉光减少一次横纵模糊迭代；网页的最高像素倍率由 1.5 调整为 1.25。

海岸船队缩小至原显示尺寸约 62%，降到更深的海面层，保留独立尾流、受损冒烟和驶离动作。城市地面同步下移。投弹的屏幕投影重新对齐，避免视觉变远后炸弹瞄到错误位置。三艘船的名称和装甲状态集中到右侧任务栏，取消覆盖在空战上方的悬浮名牌；地面敌对目标也取消了悬浮文字血条。

## 三语配音

在机库的「系统设置 → 声音与配音」选择「中文 / English / 日本語」。语言选择、开关与音量会保存到本机或当前浏览器。保留中文字幕，方便理解任务；此项为配音语言，不是整套界面语言切换。

三位驾驶员与三位敌方指挥官，每种语言覆盖同一组 110 个事件，总计 330 段原创合成录音。设置页可分别试听当前驾驶员与对应章节敌方角色。切换语言会停止旧语言正在播放和排队的台词，再准备新语言录音，避免串音。

英日驾驶员由原创、对应语言的声线参考生成；敌方则按入场、受挫、濒危与败北情绪直接演出。日语提供独立读音文本，并通过两套识别器交叉复核。音色与语气仍属于合成配音，不宣称已经过真人声优或母语听审。

## 敌方指挥官

- 加兰，利维坦舰长：老练而傲慢的男性军官。入场挑衅；装甲失守时强撑镇定；濒危时急促下令；最终仍不肯认输。
- 卡西娅，暴风眼王牌：带笑意的女性对手。先调侃护航小队，随后恼怒，失去推力时恐惧，爆炸前呼救与惊叫。
- 诺克特，天环指挥官：严肃克制的男性指挥官。正式迎战，防御失守时开始动摇，核心崩溃时意识到命令的问题，低声告别后沉默。

每人三张连续表情帧，通讯窗口随战斗事件变化。入场由真实 Boss 生成触发，受挫与濒危分别对应生命值阶段，败北由实际击毁触发。直接秒杀不会补播已经过时的濒危台词；切换章节或返回机库会清除旧对手的通讯。战后队友报告排在敌方最后一句之后。

立绘生成方式、最终提示词与资源路径见 [BossArt-1.7.md](BossArt-1.7.md)。新增三语文本见 `Tools/voice_translations_17.tsv` 与 `Assets/Resources/Voices/voice-bank.json`。
