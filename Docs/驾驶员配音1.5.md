# 1.5 · 驾驶员中文配音

三位原创成年驾驶员各有固定声线。苍凛偏清亮温柔，表现队长的安心感；绯音偏低柔慵懒，带成熟的笑意；雪璃偏清冷知性，表达克制的关怀。声音是原创合成演出，不是真人声优录音，也不模仿指定演员。

## 游戏内体验

共 76 句：39 句行动短语、3 句档案试听、9 句分角色任务简报、25 句主线通讯。选机、出击、技能、炸弹、超载、受伤、低装甲和胜负结算均有触发。主线通讯根据剧情由固定角色发声，字幕与通讯头像匹配发声者。

机库用左右键换机可听选机台词；「驾驶员档案」有试听按钮。「系统设置 → 声音与配音」提供独立开关、音量和试听，设置保存在本机或当前浏览器。网页必须先点击「进入驾驶舱」启用音频。

全场使用一条角色音轨，避免多人同时盖过彼此。重要通讯优先于一般战斗短语，危急提示可覆盖低优先级台词。短语有冷却和过期时间，切换驾驶员时去掉旧的待播内容。暂停时人声一起暂停，继续时从原位置播放。配音播放期间音乐降至原来的 54%，枪声降至 61%，撞击声降至 70%，其他音效降至 83%；声音淡入淡出，音乐播放位置保持连续。

## 资产制作

Qwen3-TTS VoiceDesign 先根据 `Tools/voice_cast.json` 的角色设定生成原创参考音；Base 模型再使用这些合成参考音生成全部台词，保持角色声音一致。没有以真人音频训练或克隆角色声线。没有用随机变调把一条声音当作三个角色。

台词按口语重写，保留句内呼吸和停顿。剪辑仅移除边缘多余静音，统一为 24 kHz 单声道 PCM16；使用 65 Hz 高通与 -18 LUFS、-2 dBTP 的响度处理。Unity 使用 Vorbis 导入，网页按压缩内存音频加载。音频文件随游戏交付，游玩时不联网生成语音、不调用语音服务。

参考音保存在 `Tools/VoiceReferences`，台词和触发映射在 `Assets/Resources/Voices/voice-bank.json`。第三方许可见 [资产与许可](资产与许可.md)。模型权重与制作环境不进入 GitHub 游戏仓库。

## 重新制作

制作工具面向 Apple Silicon。使用 Python 3.12 创建独立环境，安装 `Tools/voice-requirements.txt`；下载 MLX 格式的 Qwen3-TTS 1.7B VoiceDesign、Base 模型，需要文本核对时另下载 Qwen3-ASR 0.6B。模型文件放在游戏源码之外。

```sh
python Tools/design_voice_cast.py --model /path/to/VoiceDesign-model
python Tools/build_voice_manifest.py
python Tools/render_voices.py --model /path/to/Base-model
python Tools/check_voice_audio.py --model /path/to/ASR-model
```

第一步输出到 `Build/VoiceWork/Auditions`，不会覆盖已选定的参考音。更换声线时应先试听，再手动更新 `Tools/VoiceReferences`。渲染工具默认只生成缺失台词；使用 `--ids select_0_0,skill_2_0 --seed-offset 3001` 可重录指定句子。批次、种子、模型和硬件会影响具体波形，固定参考音保留了此版的声音依据。

## 验证范围

76 份资源均通过 Unity 单声道、时长、条目与文件对应检查。另使用独立的 Qwen3-ASR 对照中文台词，并检查静音与削波；初次发现漏词或模糊读音的短句已重录。最终没有超过 15% 拼音音节差异阈值的条目。此核对忽略声调和同音字，不等于逐句真人听审，也不能证明演出已与真人无异。

具体构建、游戏回归和浏览器语音结果记录在 [1.5 验证记录](配音验证1.5.md)。旧的 1.4 验证记录继续保留为历史版本记录。每两小时自动优化任务保持关闭。
